# Food Ordering Chatbot using Dialogflow

## Project Overview
This project is a Food Ordering Chatbot developed using Google Dialogflow. It allows users to interact with a chatbot to place food orders through natural language conversations.

## Features
- Interactive food ordering conversation.
- Collects food item and quantity from users.
- Asks for customer details.
- Provides responses based on user inputs.
- Uses Dialogflow intents and entities to understand user requests.

## Technologies Used
- Google Dialogflow
- Natural Language Processing (NLP)
- Intents and Entities

## Project Objective
The main objective of this project is to create a simple and interactive chatbot that makes the food ordering process easier through conversational interactions.
